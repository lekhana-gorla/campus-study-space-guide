# Campus Study Space Guide

## About the Project
The Campus Study Space Guide is a simple website built using HTML to help students find suitable places to study on campus. It introduces different study spaces and compares their features to help students choose the best environment for their needs.

## Features
- Information about quiet study spaces
- Information about group study spaces
- Lists of important study space features
- Step-by-step tips for choosing a study location
- A comparison table of different study spaces
- A link to quiet study space recommendations
- An image illustrating a campus study area

## Technologies Used
- HTML5

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the study space guide.

This project demonstrates basic HTML concepts, including headings, paragraphs, images, links, lists, sections, tables, and HTML document structure.
